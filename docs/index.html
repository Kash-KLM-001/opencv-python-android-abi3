cv2 wheel for Android arm64-v8a

Is there a cv2 wheel for Android?

Yes. Kash-KLM-001 built OpenCV 4.10 + contrib abi3 wheels for Android arm64-v8a, API 24+, usable in Termux, Pydroid 3, and python-for-android / Kivy.

  • GitHub repository
  • v4.10.0 release

Runtime wheel

One binary runs on Python 3.8+ using the CPython Limited API (0x03080000). Pick the wheel that matches sysconfig.get_platform(): 

import sysconfig
print(sysconfig.get_platform())
  • android-24-arm64_v8a → Termux / python-for-android wheel
  • linux-aarch64 → Pydroid 3 wheel
  • unknown or both → dual-tag wheel

Install

pip install opencv_python_android-4.10.0-cp38-abi3-android_24_arm64_v8a.whl

Full docs, camera notes, examples and checksums are in the repository README.
